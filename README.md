# las-vegas 🎲💰

拉斯维加斯掷骰游戏（简化版）：6 个赌场、8 个骰子，抢奖金。

## 玩法

- 每局开始时，6 个赌场（编号 1–6）各随机分配 3 笔奖金：$10k / $20k / $30k（打乱）。
- 每人 8 个骰子。轮到你时掷出剩余骰子，**选一个点数**，把该点数的**全部**骰子放到对应编号的赌场；该点数本局对你"锁死"，不能再放。
- 所有人骰子用完后结算每个赌场：按骰子数排名次拿奖金。
  - 独占第一拿最大一笔，第二拿次大，依此类推。
  - **并列**：k 人并列某名次时，平分该名次及之后 k−1 个名次的奖金总和（向下取整到千），然后跳过这些名次。
- 所有赌场结算完，资金多者胜。

## 用法

```bash
python3 -m las_vegas                 # 人机对战（你是玩家0）
python3 -m las_vegas --auto --games 10 --seed 42   # AI 自动对局演示
python3 -m las_vegas --auto --players 3 --verbose  # 3 人 + 首局详细输出
```

## AI 说明

1 步贪心：优先选择"放下后领先对手最多"的点数，领先相同则选奖金池大的赌场。
双发同策略时先手略占优（实测 seed 42 十局 8:2，属小样本波动）。

## 已知局限（诚实版）

- **简化规则**：原版是多轮累积、赌场奖金为单张大额钞票且有"并列第一者离开赌场"的精细规则；本项目为单局 3 笔奖金 + 并列平分简化版，不可当正式规则用。
- 无可用点数时直接弃掉剩余骰子（简化处理）。
- AI 只是 1 步贪心，不做概率期望计算；懂"锁大点数抢大奖"套路的人类通常能赢。
- 文本界面，无图形/动画/存档/悔棋；Python 3.10+，纯标准库。
